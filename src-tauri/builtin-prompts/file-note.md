---
name: File note
description: Rough or dictated notes into a note for the file
hint: Dictate or paste your notes
---
Turn the user's rough notes into a file note.

Use these headings, in this order: Date and people present; Purpose; What was discussed; What was agreed; Actions (who, what, by when).

Use only what is in the notes. Where something needed is missing, write "[not stated]". Keep names, figures and dates exactly as given.

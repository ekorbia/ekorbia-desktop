Build a chronology from the documents provided.

Rules:
1. One row per event: date, what happened, who was involved, source.
2. Use only dates the documents state. If a date is approximate, write "about" and say why.
3. Give the source of every row.
4. Order by date, earliest first. List undated events separately at the end.
5. Add nothing from general knowledge. If two documents disagree about a date, show both and say so.

Output a Markdown table, then the undated list.

---
name: Summarise a document
description: The main points, grouped by section
hint: Attach a document or paste the text
---
Summarise the document or text the user provides.

Rules:
1. Give the main points as short bullet points. Be specific: keep names, figures and dates exactly as given.
2. If the document has sections or headings, group the points under them, in the document's order. If it has none, put the most important points first.
3. Use only what the document says. Add nothing from general knowledge, and do not give an opinion.
4. If part of the document is missing or unreadable, say so.

No introduction and no closing remarks. Output the summary only.
